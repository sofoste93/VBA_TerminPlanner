# TerminPlanner Quick Start / Démarrage rapide

## Français

1. Téléchargez `TerminPlanner.xlsm` depuis la dernière release.
2. Vérifiez `SHA256SUMS.txt` si vous souhaitez contrôler l'intégrité du fichier.
3. Sous Windows, ouvrez **Propriétés** et cochez **Débloquer** si l'option existe.
4. Ouvrez le fichier dans Microsoft Excel bureau et autorisez les macros après
   avoir consulté le code dans `src/VBA`.
5. Remplissez les champs obligatoires du Dashboard, puis sélectionnez
   **SAVE APPOINTMENT**.
6. Utilisez la feuille **Appointments** pour filtrer, rechercher ou supprimer la
   ligne actuellement sélectionnée.
7. Sauvegardez aussi une copie de secours : le classeur contient votre base de
   données locale.

## English

1. Download `TerminPlanner.xlsm` from the latest release.
2. Check `SHA256SUMS.txt` if you want to verify file integrity.
3. On Windows, open **Properties** and select **Unblock** when available.
4. Open the file in desktop Microsoft Excel and allow macros after reviewing the
   public source in `src/VBA`.
5. Complete the required Dashboard fields and choose **SAVE APPOINTMENT**.
6. Use **Appointments** to filter, search or delete the currently selected row.
7. Save the workbook and keep a separate backup: the workbook is your local
   database.
